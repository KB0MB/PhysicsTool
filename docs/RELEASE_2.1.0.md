# PhysicsTool 2.1.0

## What's New

- Added Link armor and weapon previews, including equipment swaps, sheaths, quivers and arrows.
- Added cloth-to-model bone matching, cloth fitting and bone-branch resizing without changing bone scale values.
- Added HKCL FBX export with skeletons, particle meshes and colliders.
- Added Textured, Wireframe and Edged Faces display modes, with separate Particles, Bones and Colliders visibility controls.
- Improved TotK cloth and helper-bone simulation, accessory attachments and animation timeline stability.
- Improved viewport performance with large cloth files and fixed model alignment and camera jumps.
- Improved BPHYSICS wind settings and added TotK cloth-reaction inspection.
- Preserved conversion filenames, made Wii U the initial HKCL target and remembered the last selected platform.
- Fixed editor transform shortcuts and updated documentation and translations.

## Running PhysicsTool

Extract the whole ZIP before starting the app. Each build includes the .NET runtime and all four languages.

- Windows: use win-x64 for most PCs, or win-arm64 for Windows on ARM.
- Linux: choose linux-x64 or linux-arm64. A glibc-based desktop with ICU, X11/XWayland, fontconfig and working OpenGL drivers is required.
- macOS 15 or later: use osx-arm64 for Apple silicon or osx-x64 for Intel, then open PhysicsTool.app. The app is not notarized.

Simulation and materials are previews and may differ from the games. Make sure to keep an original copy as a backup!
